---
title: "Get News"
api: "GET https://api.tradingnews.press/v1/news"
description: "Retrieve recent financial news articles"
---

## Query Parameters

<ParamField query="limit" type="integer" default="50" optional>
  Number of articles to return. Min: 1, Max: 100.
</ParamField>

<ParamField query="since" type="string" optional>
  Only return articles received at or after this ISO 8601 datetime. Example: `2026-04-07T00:00:00Z`
</ParamField>

<ParamField query="urgency" type="string" optional>
  Filter by urgency level: `breaking`, `flash`, or `regular`.
</ParamField>

<ParamField query="order" type="string" default="desc" optional>
  `desc` returns newest first; `asc` returns oldest first. Combine `asc` with `since` to page forward.
</ParamField>

<ParamField query="after_id" type="string" optional>
  Forward-paging cursor: the last article's 26-character `id`. Requires `order=asc` and `since` set to that article's `received_at`.
</ParamField>

<ParamField query="insights" type="boolean" default="false" optional>
  Max only. Explicitly request `insights=true` to add public News Insights; default responses are unchanged. Starter and Pro opt-in requests return `403`. See [News Insights](/concepts/news-insights).
</ParamField>

## Response

<ResponseField name="count" type="integer">
  Number of articles returned.
</ResponseField>

<ResponseField name="articles" type="Article[]">
  Array of article objects. Max-plan responses additionally include `tickers` with per-ticker sentiment. Max requests with `insights=true` also include `insights`. Starter and Pro responses omit both fields.
</ResponseField>

<Note>
  Starter keys can query articles received in the last 24 hours; Pro and Max keys can query the last 7 days. Older `since` values are silently clamped to the allowed window.
</Note>

<RequestExample>

```bash cURL
curl -H "X-API-Key: YOUR_KEY" \
  "https://api.tradingnews.press/v1/news?limit=5&urgency=breaking"
```

```python Python
import httpx

resp = httpx.get(
    "https://api.tradingnews.press/v1/news",
    headers={"X-API-Key": "YOUR_KEY"},
    params={"limit": 5}
)
articles = resp.json()["articles"]
```

</RequestExample>
